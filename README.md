# 📚 Chat With Your PDF

A Retrieval-Augmented Generation (RAG) application that allows users to ask questions about a PDF and receive answers based only on the information retrieved from the document.

## 🚀 Features

- PDF text extraction
- Text chunking
- Semantic embeddings
- ChromaDB vector database
- Semantic similarity search
- Gemini AI answer generation
- Page-level source tracking
- Streamlit web interface
- Context-based answers to reduce unsupported responses

## 🧠 How It Works

PDF
↓
Text Extraction
↓
Text Chunking
↓
Sentence Transformers Embeddings
↓
ChromaDB
↓
Question Embedding
↓
Relevant Chunks Retrieved
↓
Gemini
↓
Answer + Source Pages

## 🛠️ Technologies

- Python
- Streamlit
- ChromaDB
- Sentence Transformers
- LangChain Text Splitters
- Google Gemini API
- PyPDF
